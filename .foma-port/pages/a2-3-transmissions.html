Передача данныхData transmission

Тема A2.3 отвечает на вопрос: «Как именно данные физически и логически добираются от одного устройства до другого?». Здесь четыре больших блока: IP-адресация (как устройства называются), среды передачи (по чему идут сигналы), коммутация пакетов (как сообщение режется на куски и доставляется), и маршрутизация (как роутеры выбирают путь). Плюс — характеристики канала (пропускная способность, задержка, джиттер) и обнаружение ошибок. Topic A2.3 answers the question “How exactly do data physically and logically travel from one device to another?” It has four main parts: IP addressing (how devices are named), transmission media (what the signals travel through), packet switching (how a message is cut into pieces and delivered), and routing (how routers choose the path). It also covers the characteristics of a channel (bandwidth, latency, jitter) and error detection.

2. IP-адресация (A2.3.1)2. IP addressing (A2.3.1)

Internet Protocol (IP) — это протокол, который отвечает за маршрутизацию и доставку пакетов между сетями. В центре IP — IP-адрес: уникальное числовое имя устройства в сети. Internet Protocol (IP) is the protocol responsible for routing and delivering packets between networks. At the centre of IP is the IP address: a unique numerical name for a device on the network.

🇬🇧 English summary — IP addressing. An IP address is a unique numeric identifier assigned to a device on an IP network so that routers know where to deliver packets. IPv4 uses 32 bits (about 4.3 billion addresses, written in dotted decimal such as 192.168.1.1) and is essentially exhausted. IPv6 uses 128 bits, written as eight hex groups, with mandatory IPsec support. Public addresses are globally unique and routable on the open internet; private ranges (RFC 1918: 10.x, 172.16–31.x, 192.168.x) are reused inside local networks. Static IPs stay fixed (servers, printers); dynamic ones are leased by a DHCP server. NAT lets many private hosts share one public address by rewriting source IP and port. A subnet mask (or CIDR suffix like /24) splits an address into network and host parts. The loopback 127.0.0.1 always refers to the local machine.
IP-адрес. Уникальный числовой идентификатор устройства в IP-сети. По нему другие устройства понимают, «куда» отправлять пакет. IP address. A unique numerical identifier for a device on an IP network. Other devices use it to work out “where” to send a packet.

🔢 2.1. IPv4 vs IPv6

Двух версий IP-адресов хватит для экзамена: IPv4 (старый, заканчивается) и IPv6 (новый, огромное пространство). Two versions of IP addresses are enough for the exam: IPv4 (the old one, running out) and IPv6 (the new one, with a huge address space).

🌍 2.2. Публичные и частные IP-адреса🌍 2.2. Public and private IP addresses

Публичный IP (Public IP)Public IP

  • Назначается устройству, которое напрямую выходит в интернет.Assigned to a device that connects directly to the internet.
  • Уникален в масштабах всего интернета — двух одинаковых одновременно быть не может.Unique across the whole internet: two identical addresses cannot exist at the same time.
  • Управляется IANA (Internet Assigned Numbers Authority) и региональными регистраторами.Managed by IANA (Internet Assigned Numbers Authority) and by regional registries.

  • Используется внутри частной сети (дом, офис) и не маршрутизируется в открытом интернете.Used inside a private network (home, office) and not routed on the open internet.

  • Примеры устройств: домашний компьютер, принтер, смартфон в Wi-Fi.Examples of devices: home computer, printer, smartphone on Wi-Fi.

🔁 2.3. Loopback-адрес 127.0.0.1🔁 2.3. Loopback address 127.0.0.1

127.0.0.1 — это специальный loopback-адрес: устройство отправляет пакет «само себе», не выходя в физическую сеть. Используется для тестирования сетевого стека и локальных серверов. В IPv6 такой же смысл имеет ::1 (двойное двоеточие :: сокращает подряд идущие нули). Весь диапазон 127.0.0.0 – 127.255.255.255 зарезервирован для loopback, но на практике используют 127.0.0.1. 127.0.0.1 is a special loopback address: a device sends a packet “to itself”, without leaving the physical network. It is used to test the network stack and local servers. In IPv6, ::1 has the same meaning (the double colon :: shortens consecutive zeros). The whole range 127.0.0.0 – 127.255.255.255 is reserved for loopback, but in practice 127.0.0.1 is used.

Реальный пример. Веб-разработчик запускает локальный сервер и открывает в браузере http://127.0.0.1:3000 или http://localhost:3000 — браузер обращается к серверу, который работает на том же компьютере. Real example. A web developer starts a local server and opens http://127.0.0.1:3000 or http://localhost:3000 in the browser. The browser connects to the server that runs on the same computer.

📌 2.4. Статические и динамические IP📌 2.4. Static and dynamic IP

Статический (Static)Static

  • Адрес постоянно закреплён за устройством, не меняется.The address is permanently assigned to the device and does not change.
  • Настраивается вручную администратором.Set by hand by the administrator.
  • Нужен серверам (веб, почта, DNS, принтер в офисе), к которым обращаются по конкретному адресу.Needed by servers (web, mail, DNS, an office printer) that are reached at a specific address.
  • Минус: трудоёмко при тысячах устройств — нужно вести таблицу вручную.Drawback: time-consuming with thousands of devices, because the table has to be kept by hand.

Динамический (Dynamic)Dynamic

  • Адрес назначается на время, при подключении к сети.The address is assigned for a limited time when the device connects to the network.
  • Раздаёт DHCP-сервер из пула свободных адресов.Issued by a DHCP server from a pool of free addresses.
  • При повторном подключении устройство может получить уже другой IP.When the device reconnects, it may get a different IP.
  • Плюс: экономит ограниченный пул адресов; масштабируется.Advantage: saves a limited pool of addresses; scales well.

🌉 2.5. NAT — сетевая трансляция адресов🌉 2.5. NAT — network address translation

NAT (Network Address Translation) решает главную боль IPv4: адресов не хватает. NAT позволяет сотням частных адресов прятаться за одним публичным. NAT (Network Address Translation) solves the main problem of IPv4: there are not enough addresses. NAT allows hundreds of private addresses to hide behind one public address.

NAT: три частных IP «маскируются» за единственным публичным адресом роутера.NAT: three private IPs are “masked” behind the router’s single public address.

Как это работает по шагам:How it works, step by step:

  1. Устройство в частной сети отправляет пакет в интернет.A device on a private network sends a packet to the internet.
  2. NAT-устройство (обычно роутер) заменяет частный IP в заголовке на свой публичный IP. Также меняется порт-источник, чтобы потом понять, кому вернуть ответ.The NAT device (usually the router) replaces the private IP in the header with its own public IP. The source port is also changed, so that it can later tell which device the reply goes back to.
  3. Запись «частный IP + порт ↔ публичный IP + порт» сохраняется в NAT-таблице.The entry “private IP + port ↔ public IP + port” is saved in the NAT table.
  4. Ответ из интернета приходит на публичный IP. NAT смотрит в таблицу и пересылает пакет «правильному» устройству внутри сети.The reply from the internet arrives at the public IP. NAT checks the table and forwards the packet to the correct device inside the network.
Реальный пример. У вас дома подключены ноутбук, телефон, телевизор, два умных динамика и игровая консоль — всем шести устройствам провайдер выдал один публичный IP. Каждое получает свой частный IP 192.168.0.x, а роутер с NAT обрабатывает их совместный выход в сеть. Real example. At home you have a laptop, a phone, a TV, two smart speakers and a games console connected. The provider gave all six devices one public IP. Each one gets its own private IP 192.168.0.x, and the router with NAT handles their shared connection to the internet.

🧮 2.6. Подсеть и маска подсети (intro)🧮 2.6. Subnet and subnet mask (intro)

Маска подсети (subnet mask) — это битовый «фильтр», который делит IP-адрес на две части: сетевая часть (она же — номер подсети) и хост-часть (номер конкретного устройства). Устройства с одинаковой сетевой частью находятся «в одной подсети» и могут общаться напрямую — без роутера. Subnet mask is a bit “filter” that divides an IP address into two parts: the network part (also called the subnet number) and the host part (the number of the particular device). Devices with the same network part are “in the same subnet” and can communicate directly, without a router.

Чтобы узнать сетевую часть, делается побитовая операция AND между IP и маской.To find the network part, a bitwise AND operation is carried out between the IP address and the mask.

Пример. IP 192.168.1.10 + маска 255.255.255.0 → сетевой адрес 192.168.1.0, хост .10. Все устройства 192.168.1.1 – 192.168.1.254 находятся в одной локальной сети. Example. IP 192.168.1.10 + mask 255.255.255.0 → network address 192.168.1.0, host .10. All devices 192.168.1.1 – 192.168.1.254 are in the same local network.

В CIDR-нотации то же самое записывают как 192.168.1.0/24 — «24» означает, что первые 24 бита из 32 заняты под сетевую часть, а оставшиеся 8 — под хосты (256 адресов, из которых 254 могут быть назначены устройствам; первый — адрес сети, последний — широковещательный). In CIDR notation the same thing is written as 192.168.1.0/24: “24” means that the first 24 of the 32 bits are used for the network part, and the remaining 8 for hosts (256 addresses, of which 254 can be assigned to devices; the first is the network address and the last is the broadcast address).

3. Среды передачи данных (A2.3.2)3. Transmission media (A2.3.2)

Сигнал должен по чему-то передаваться. Есть три большие категории: оптоволокно, витая пара (медь) и беспроводные технологии. Для каждой среды важны 7 факторов: пропускная способность, сложность установки, цена, дальность, помехоустойчивость, затухание, надёжность и безопасность. A signal must be carried through something. There are three large categories: fibre-optic, twisted pair (copper) and wireless technologies. For each medium, 7 factors matter: bandwidth, installation complexity, cost, range, interference resistance, attenuation, reliability and security.

🇬🇧 English summary — transmission media. Three main families carry network signals. Twisted-pair copper cable (UTP or shielded STP) is cheap and easy to install, but suffers from electromagnetic interference and is usually limited to roughly 100 metres before a repeater is needed. Coaxial cable, with a central core inside braided shielding, was common in early Ethernet and is still used for cable TV and last-mile broadband. Fibre-optic sends pulses of light through glass strands, giving very high bandwidth, very long reach, low attenuation and immunity to EMI, but cabling and termination are expensive and require trained technicians. Wireless media — Wi-Fi, Bluetooth, cellular, satellite — use radio or microwave signals, offering mobility but suffering from interference, obstacles and weaker security. Exam answers should always compare at least three factors such as speed, range and reliability.

📡 3.2. Кратко по каждой среде📡 3.2. Summary of each medium

💡 Оптоволокно (Fibre-optic)💡 Fibre-optic

Как работает: данные передаются как импульсы света по тонким стеклянным или пластиковым волокнам. Используется два режима — одномодовый (на дальние дистанции) и многомодовый (короткие, внутри ЦОД).How it works: data is sent as pulses of light along thin glass or plastic fibres. Two modes are used: single-mode (for long distances) and multi-mode (short runs, inside data centres).

Где применяется в жизни:Where it is used in real life:

  • Магистральные каналы между ЦОД и трансатлантические подводные кабели — весь интернет «висит» на оптике.Backbone links between data centres and transatlantic undersea cables — the whole internet relies on fibre.
  • FTTH (Fiber-to-the-Home) — оптика к квартире, скорости 1 Гбит/с и выше.FTTH (Fiber-to-the-Home) — fibre to the flat, with speeds of 1 Gbit/s and above.
  • Внутри современных дата-центров между серверными стойками.Inside modern data centres, between server racks.

🧵 Витая пара (Twisted pair)🧵 Twisted pair

Как работает: пары медных проводов скручены попарно — это снижает взаимные помехи. Две разновидности:How it works: pairs of copper wires are twisted together, which reduces mutual interference. There are two types:

  • UTP (Unshielded) — без экрана; дёшево, повсеместно. Категории Cat 5e, Cat 6, Cat 6a, Cat 7.UTP (Unshielded) — without a shield; cheap and found everywhere. Categories Cat 5e, Cat 6, Cat 6a, Cat 7.
  • STP (Shielded) — с дополнительным экраном из фольги или оплётки; защищает от EMI; применяется на заводах, в больницах рядом с электромагнитным оборудованием.STP (Shielded) — with an extra shield of foil or braid; protects against EMI; used in factories and in hospitals near electromagnetic equipment.

Где применяется:Where it is used:

  • Кабельная разводка офисов (от коммутатора к каждому рабочему месту через RJ-45 розетку).Cabling in offices (from the switch to each workstation through an RJ-45 socket).
  • Соединение домашнего компьютера с роутером, когда нужна стабильность лучше Wi-Fi.Connecting a home computer to the router when more stability is needed than Wi-Fi gives.

📡 Беспроводные технологии (Wireless)📡 Wireless technologies

Как работает: данные передаются электромагнитными волнами разных частот — радио (Wi-Fi 2,4/5/6 ГГц), инфракрасное (пульты), микроволны (Bluetooth, мобильная связь, спутник).How it works: data is sent by electromagnetic waves of different frequencies — radio (Wi-Fi 2.4/5/6 GHz), infrared (remote controls), microwaves (Bluetooth, mobile networks, satellite).

Где применяется:Where it is used:

  • Wi-Fi — школьная и домашняя сеть.Wi-Fi — school and home networks.
  • Bluetooth — наушники, мышь, клавиатура (короткая дистанция, низкое энергопотребление).Bluetooth — headphones, mouse, keyboard (short range, low power consumption).
  • Сотовая связь (4G / 5G) — мобильный интернет.Cellular (4G / 5G) — mobile internet.

4. Характеристики канала: пропускная способность, задержка, джиттер4. Channel characteristics: bandwidth, latency, jitter

На экзамене легко путают эти термины. Каждый описывает свой аспект качества связи. In the exam these terms are easy to confuse. Each one describes its own aspect of the quality of communication.

🇬🇧 English summary — bandwidth, throughput, latency, jitter. These four metrics describe link quality and are often confused. Bandwidth is the theoretical maximum data rate of a channel, measured in bits per second (Mbps, Gbps) — the "pipe diameter". Throughput is the actual rate of useful data delivered; it is always less than bandwidth because of overhead, congestion and protocol limits. Latency is the time, in milliseconds, taken for a single packet to travel from sender to receiver — what gamers call ping. Jitter measures the variation in latency between consecutive packets; high jitter causes audio and video to stutter even when average latency is low. Bulk file downloads care most about bandwidth and throughput, while real-time video calls and online games depend on low latency and low jitter.

5. Коммутация пакетов (A2.3.3)5. Packet switching (A2.3.3)

Когда вы отправляете данные в сеть, они не идут одним куском. Они режутся на маленькие порции — пакеты — и каждый пакет отправляется независимо. Этот метод называется packet switching (коммутация пакетов) и лежит в основе всего интернета. When you send data over a network, it does not travel in one piece. It is cut into small portions — packets — and each packet is sent independently. This method is called packet switching and it underlies the whole internet.

🇬🇧 English summary — packet switching. In packet switching, a message is divided into small units called packets. Each packet has a header (source and destination IP, sequence number, error-check code) plus a payload of data. Wrapping data with headers is called encapsulation; unwrapping at the destination is decapsulation. Packets travel independently through the network and can take different routes; the receiver reorders them using the sequence numbers and asks for any missing ones to be resent. This makes the network resilient (failed links are routed around), efficient (one channel carries many users' packets) and scalable. By contrast, circuit switching (used in the old telephone network) reserves a dedicated path for the whole conversation, giving guaranteed bandwidth but wasting capacity when idle. Within a LAN, a switch forwards frames by MAC address; between networks a router consults a routing table and forwards each packet to the next hop.
Пакет (Packet). Структурная единица данных в сети: payload (полезная нагрузка — кусок исходных данных) + header (заголовок с метаданными: адрес отправителя и получателя, номер в последовательности, контрольная сумма). Packet. A structural unit of data on a network: the payload (the useful load — a piece of the original data) + a header (metadata: the sender’s and receiver’s addresses, the sequence number, a checksum).

🧩 5.1. Зачем делить данные на пакеты🧩 5.1. Why split data into packets

  • Параллельность. Разные пакеты могут идти разными путями — сеть используется эффективнее.Parallelism. Different packets can take different routes — the network is used more efficiently.
  • Надёжность. Если один пакет потерян или повреждён, перепосылается только он, а не всё сообщение.Reliability. If one packet is lost or damaged, only that packet is sent again, not the whole message.
  • Адаптивность. Если один канал перегружен, роутеры могут отправить следующий пакет в обход.Adaptability. If one link is overloaded, routers can send the next packet around it.
  • Справедливость. Канал не «забивается» одним длинным сообщением — между его пакетами проходят чужие.Fairness. One long message does not “clog” the channel — packets from other messages pass between its packets.

6. Обнаружение ошибок: parity, checksum, CRC6. Error detection: parity, checksum, CRC

Любая передача — это риск, что один или несколько бит «перевернутся» из-за помех. Поэтому в каждый пакет встраивают код для проверки на ошибки. Учебник Oxford упоминает error-checking codes в составе заголовка; конкретные методы — это классика курса. Every transmission carries the risk that one or more bits will “flip” because of interference. That is why an error-checking code is built into every packet. The Oxford textbook mentions error-checking codes as part of the header; the specific methods are classic topics of the course.

🇬🇧 English summary — error detection. Every transmission risks bit flips due to electrical noise or interference, so packets carry extra bits used to detect errors. A parity bit appends a single 1 or 0 so the total number of ones is even or odd; it catches any odd number of flipped bits but misses even-numbered errors. A checksum sums the bytes of the message into a small fixed-size value that the receiver recomputes and compares; it catches most random corruption but can miss errors that cancel out. A Cyclic Redundancy Check (CRC) treats the data as a polynomial and stores the remainder when divided by a fixed generator, catching nearly all single-bit and burst errors typical of real channels. CRC is used in Ethernet frames, Wi-Fi, USB and archive formats. These methods only detect errors; correction needs Hamming or Reed-Solomon codes, or simple retransmission as TCP does.

8. Маршрутизация: статическая vs динамическая AHL8. Routing: static vs dynamic AHL

Это тема A2.3.4 — её формально проходят только в HL, но для глубокого понимания сетей полезно знать всем. This is topic A2.3.4 — formally it is studied only at HL, but it is useful for everyone to know, for a deep understanding of networks.

🇬🇧 English summary — routing (AHL). A router moves packets between networks by consulting its routing table: rules that map a destination network to the next hop (the neighbouring router or output interface). With static routing, an administrator manually enters every route. This is simple, predictable and uses few resources, but does not scale and must be edited by hand whenever the topology changes — suitable for small offices or home networks. With dynamic routing, routers exchange reachability information using protocols such as RIP (uses hop count), OSPF (uses link cost, common inside an organisation) and BGP (between large internet providers). Routes are recalculated automatically when a link fails; the time for all routers to agree on the new topology is called convergence. Dynamic routing scales to thousands of routers but consumes more CPU, memory and bandwidth, and is harder to configure and secure.

📋 8.1. Что такое routing📋 8.1. What is routing

Каждый роутер хранит routing table (таблицу маршрутизации) — это набор правил «если адрес назначения такой-то, отправь пакет в такой-то порт / на такой-то соседний роутер». Когда приходит пакет, роутер берёт IP-адрес получателя из заголовка, ищет совпадение в таблице и пересылает на следующий хоп (next hop). Each router stores a routing table — a set of rules such as “if the destination address is this one, send the packet to this port / to this neighbouring router”. When a packet arrives, the router takes the receiver’s IP address from the header, looks for a match in the table and forwards the packet to the next hop.

🛠️ 8.2. Статическая маршрутизация🛠️ 8.2. Static routing

  • Администратор вручную прописывает в роутере: «для сети X next hop — Y».The administrator manually enters into the router: “for network X the next hop is Y”.
  • Хранятся: адрес сети назначения, маска подсети, следующий hop или выходной интерфейс.Stored: the destination network address, the subnet mask, the next hop or the exit interface.
  • Плюсы: просто, предсказуемо, мало нагружает CPU/память; нет лишнего трафика обмена маршрутами; можно жёстко контролировать пути ради безопасности.Advantages: simple, predictable, puts little load on the CPU and memory; no extra traffic from exchanging routes; paths can be tightly controlled for security.
  • Минусы: при изменении топологии (упал линк, добавилась сеть) нужно править вручную; не масштабируется на сотни роутеров; в случае сбоя пакеты могут «стучаться в стену».Disadvantages: when the topology changes (a link goes down, a network is added) it must be edited by hand; it does not scale to hundreds of routers; when a failure occurs, packets may “bang against a wall”.
  • Где подходит: маленькие стабильные сети — небольшой офис, домашний роутер.Where it suits: small stable networks — a small office, a home router.

🤖 8.3. Динамическая маршрутизация🤖 8.3. Dynamic routing

  • Роутеры сами обмениваются информацией о доступных сетях по специальным routing-протоколам.Routers exchange information themselves about the networks they can reach, using special routing protocols.
  • Известные протоколы: RIP (Routing Information Protocol — старый, использует hop count), OSPF (Open Shortest Path First — внутренний протокол, считает «стоимость» канала), BGP (Border Gateway Protocol — между крупными провайдерами в интернете).Known protocols: RIP (Routing Information Protocol — old, uses hop count), OSPF (Open Shortest Path First — an internal protocol that calculates the “cost” of a link), BGP (Border Gateway Protocol — between large providers on the internet).
  • Метрики выбора маршрута: число хопов, пропускная способность, задержка, надёжность.Route selection metrics: number of hops, bandwidth, latency, reliability.
  • При изменении топологии (упал кабель) протокол пересчитывает маршруты автоматически. Время, нужное на согласованное понимание новой топологии всеми роутерами, называется convergence (сходимость).When the topology changes (a cable goes down), the protocol recalculates the routes automatically. The time needed for all routers to agree on the new topology is called convergence.
  • Плюсы: сам адаптируется к изменениям, масштабируется на большие сети.Advantages: adapts to changes by itself, scales to large networks.
  • Минусы: сложнее настроить и понять; нагружает CPU/память роутера; обмен маршрутами потребляет полосу; есть риски безопасности, если протокол не защищён.Disadvantages: harder to configure and understand; loads the router’s CPU and memory; exchanging routes uses bandwidth; there are security risks if the protocol is not protected.

Реальный пример. В сети одной школы (10–20 коммутаторов) обычно настраивают статическую маршрутизацию — топология стабильна. А в сети крупного оператора связи (тысячи маршрутизаторов в разных странах) работают OSPF внутри и BGP на границах — иначе администраторы не успели бы вручную поддерживать таблицы. Real example. In the network of one school (10–20 switches) static routing is usually configured — the topology is stable. In the network of a large telecom operator (thousands of routers in different countries), OSPF runs inside and BGP runs at the borders — otherwise administrators would not have time to keep the tables up to date by hand.

Что важно запомнитьWhat to remember

  • IPv4 vs IPv6: 32 бита (≈ 4,3 млрд) против 128 бит (≈ 3,4 × 10³⁸). IPv6 — будущее, IPv4 — настоящее за счёт NAT.IPv4 vs IPv6: 32 bits (≈ 4.3 billion) against 128 bits (≈ 3.4 × 10³⁸). IPv6 is the future; IPv4 is the present, thanks to NAT.
  • Публичный IP — глобально уникален и маршрутизируется в интернете. Частный IP — только внутри LAN, диапазоны RFC 1918 (10.x, 172.16–31.x, 192.168.x).Public IP — globally unique and routed on the internet. Private IP — only inside a LAN; the ranges of RFC 1918 (10.x, 172.16–31.x, 192.168.x).
  • NAT — массовая трансляция «много частных в один публичный», экономит IPv4.NAT — large-scale translation of “many private into one public”, saves IPv4 addresses.
  • Маска подсети делит IP на сетевую и хост-часть; в CIDR записывается как /24.Subnet mask divides the IP address into a network part and a host part; in CIDR it is written as /24.
  • Среды передачи: оптоволокно — быстро, далеко, дорого, без помех; витая пара — дёшево, до 100 м, чувствительна к EMI; беспроводные — мобильно, но уязвимо к помехам и перехвату.Transmission media: fibre-optic — fast, long range, expensive, immune to interference; twisted pair — cheap, up to 100 m, sensitive to EMI; wireless — mobile, but vulnerable to interference and interception.
  • Bandwidth ≠ throughput ≠ latency ≠ jitter — все четыре про разное; типичная экзаменационная ловушка.Bandwidth ≠ throughput ≠ latency ≠ jitter — all four are about different things; a typical exam trap.
  • Packet switching: данные → сегментация → пакеты с заголовками → независимая маршрутизация → сборка по sequence numbers. Этим живёт весь интернет.Packet switching: data → segmentation → packets with headers → independent routing → reassembly using sequence numbers. The whole internet runs on this.
  • Заголовок пакета содержит IP-адреса источника и приёмника, sequence number, контрольные коды (parity / checksum / CRC).The packet header contains the IP addresses of the source and the receiver, the sequence number and error-checking codes (parity / checksum / CRC).
  • Switch работает по MAC-адресам внутри LAN; router — по IP-адресам между сетями, использует routing table и выбирает next hop.A switch works by MAC addresses inside a LAN; a router works by IP addresses between networks, uses a routing table and chooses the next hop.
  • Static vs dynamic routing (AHL): статика — вручную, для маленьких сетей; динамика (RIP, OSPF, BGP) — автоматически, адаптивно, для больших сетей. Ключевое понятие — convergence.Static vs dynamic routing (AHL): static — by hand, for small networks; dynamic (RIP, OSPF, BGP) — automatic, adaptive, for large networks. The key concept is convergence.
  • На экзамене: вопросы «compare» и «contrast» отвечай минимум через 3 фактора; обязательно используй термины encapsulation, routing table, next hop, subnet mask, NAT.In the exam: for “compare” and “contrast” questions answer through at least 3 factors; be sure to use the terms encapsulation, routing table, next hop, subnet mask, NAT.
